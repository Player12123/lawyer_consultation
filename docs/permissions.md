# 角色与权限基线

## 普通用户 `agent`

- 首次使用手机号验证码登录时自动注册。
- 使用咨询智能体、查看自己的完整咨询记录、清空当前上下文、修改个人资料和换绑手机号。
- 不能查看其他用户、组织统计或管理账号。

## 普通管理员/组长 `group_admin`

- 数量不限，必须归属一个组。
- 查看本组成员的必要资料、账号状态、咨询量和业务类型分布。
- 启用或禁用本组普通用户；不能删除用户、改变角色、管理其他组或查看成员咨询全文。
- 不能操作系统管理员，也不能操作自己以绕过权限控制。

## 系统管理员 `system_admin`

- 每个租户始终只有一个，由产品交付时指定。
- 通过该账号的手机号换绑完成负责人交接，不通过“提升另一个账号”完成交接。
- 查看全租户用户、分组及咨询量/业务类型统计；新建分组和预录入用户；分配普通用户/组长角色和分组；启停及逻辑删除账号。
- 不能创建第二个系统管理员，也不能删除或降级自身。
- 查看咨询全文属于敏感操作：默认界面不展示；如后续开放，必须逐次审计并说明用途。

## 服务端强制规则

- 权限判断同时校验租户、角色、分组、目标用户和账号状态。
- 所有查询先按租户收敛；组长查询再按其 `group_id` 收敛。
- 前端传入的角色、用户 ID、组 ID 和统计范围均不可信。
- 用户被禁用或删除时立即撤销其全部会话。
