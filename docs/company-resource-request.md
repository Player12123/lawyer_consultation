# 需要向公司申请的资源

公网部署前请一次性准备以下资料，不要把密钥直接发到聊天工具或工单正文。

## 必需资源

- 云厂商、地域、VPC/私有网络和一台 Linux LTS 云服务器。
- 固定公网 IP 或域名；域名 DNS 管理权限；HTTPS 证书申请权限。
- WAF/CDN 或云负载均衡；安全组配置权限。
- MySQL 实例、私网地址、备份策略、恢复演练窗口。
- 可由 API 服务器访问的短信 HTTPS/内网地址、App ID、Password、签名/模板确认。
- AI 接口地址、模型名、密钥、数据不用于训练的合同或服务条款确认。
- 法条和类案接口的 `x-app-id`、`x-app-secret`、正式地址及调用配额。

## 管理资料

- 客户租户名称和固定 `TENANT_ID`。
- 由系统管理员后台创建或设置的首位 `system_admin` 账号资料；短信自助登录账号不得作为系统管理员来源。
- 需要加入的初始组长和成员名单。
- 数据保留期限、隐私政策、个人信息处理授权和客户合同要求。
- 运维联系人、告警接收人、发布窗口和回滚负责人。

## 不要提供给聊天窗口的内容

- 短信密码、AI Key、`x-app-secret`、数据库密码、Pepper、咨询加密密钥、TLS 私钥。

这些值应由技术人员写入云密钥管理服务或服务器上权限为 `600` 的环境文件。
