# 依赖漏洞审计记录

每次生产发布前和每月至少一次执行以下命令：

```bash
npm run security:audit
```

该命令会向 npm 安全服务查询生产依赖，并在发现 `high` 或 `critical` 漏洞时返回非零状态。网络不可用、npm 服务不可达或审计命令本身失败时，必须记录为“未完成”，不能标记为通过。

## 记录模板

| 字段 | 填写内容 |
| --- | --- |
| 执行时间（含时区） |  |
| 执行人 |  |
| 发布版本 / Git 提交 |  |
| 命令 | `npm run security:audit` |
| 结果 | 通过 / 发现漏洞 / 未完成 |
| high / critical 数量 |  |
| npm 审计输出或受控工单链接 |  |
| 处置结论与负责人 |  |

发现 `high` 或 `critical` 漏洞时，默认阻止发布；只有业务负责人和安全负责人共同接受风险并写明临时缓解措施后，才允许例外发布。
