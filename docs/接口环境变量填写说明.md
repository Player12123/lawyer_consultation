# `.env.local` 填写说明

你只需要修改项目根目录的 `.env.local`。这个文件只保存必须由你或服务商提供、不能硬编码的地址和密钥；超时时间、思考模式、验证码有效期等程序行为不放在这里。

`.env.local` 已被 Git 忽略。不要发送给他人，不要截图，不要提交到代码仓库。

## 1. 数据库与系统安全密钥

```ini
DATABASE_URL=mysql://用户名:密码@数据库地址:3306/数据库名
TENANT_ID=客户的固定租户ID
SESSION_TOKEN_PEPPER=随机安全字符串
PHONE_HASH_PEPPER=另一条随机安全字符串
VERIFICATION_CODE_PEPPER=第三条随机安全字符串
CONSULTATION_CONTENT_KEY=咨询正文专用随机安全字符串
```

四条安全字符串必须彼此不同。它们分别用于会话令牌、手机号脱敏哈希、验证码哈希和咨询正文加密，不能使用姓名、手机号或简单口令。已存在的旧密文仍可由程序兼容读取；填写专用密钥后，新咨询会自动使用独立密钥加密。

## 2. 短信服务

```ini
SMS_BESTONE_ENDPOINT=http://smsswitch.b114.com.cn/sendMsgNew
SMS_BESTONE_APP_ID=服务商提供的ID
SMS_BESTONE_PASSWORD=服务商提供的密码
```

`type=1`、短信内容、验证码和 5 分钟有效期由程序生成，`sign` 按供应商要求传空，不需要写进环境变量。

当前供应商只提供 HTTP，因此仅适合本机联调。正式交付前应要求供应商提供 HTTPS 或专线/内网访问方式。

## 3. AI 服务

```ini
AI_BASE_URL=https://aichat.bestone.com/kdlsnt/v3
AI_API_KEY=服务商提供的Bearer密钥（只填密钥本身）
AI_MODEL=bstaichat-V101
```

程序会在 `AI_BASE_URL` 后追加 `/chat/completions`，实际调用地址为：

`https://aichat.bestone.com/kdlsnt/v3/chat/completions`

思考模式当前由程序固定为 `disabled`，不需要填写。

## 4. 法条与类案工具

```ini
LEGAL_TOOLS_X_APP_ID=服务商提供的x-app-id
LEGAL_TOOLS_X_APP_SECRET=服务商提供的x-app-secret
LAW_SEARCH_ENDPOINT=https://openapi.bestone.com/fatiaomatch/lawmatch/laws/match
CASE_SEARCH_ENDPOINT=https://openapi.bestone.com/caseanswer/api/v2/precise_search
```

两项工具共用同一组 `x-app-id` / `x-app-secret`。程序会按接口要求分别构造参数，不能只做无参数连接测试：

- 法条接口：`question`、`top_n`
- 类案接口：`keyword_text`、`fact_text`、`intent_text`、`top_k`、`score_threshold`

## 5. 修改后启动

```bash
npm run api:start
```

管理员不通过环境变量自动产生。每个租户的唯一系统管理员由交付时写入数据库，之后只通过该账号的手机号换绑完成负责人交接。普通手机号首次验证登录会自动注册为普通用户。
