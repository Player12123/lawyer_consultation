# 数据保留与最小化基线

| 数据 | 默认保留 | 可见范围 | 规则 |
| --- | --- | --- | --- |
| 咨询问题与回答 | 1 年 | 本人；敏感审计模式下的系统管理员 | 加密存储；到期后删除正文或整条记录，聚合统计可保留 |
| 咨询量与业务类型聚合 | 长期 | 组长看本组，系统管理员看全局 | 不含咨询全文 |
| 技术错误日志 | 200 天 | 产品运维内部 | 自动按到期时间清理；不得含密钥、验证码、完整手机号和咨询全文 |
| 身份与管理审计 | 按交付合规策略 | 受限管理人员 | 追加写入；记录谁、何时、对什么对象做了什么 |
| 验证码 | 到期后仅短期排障所需 | 服务端 | 只存哈希；禁止存明文 |
| 会话 | 到期或撤销后按清理任务删除 | 服务端 | 只存令牌哈希 |

当前迭代实现 200 天技术日志到期字段和清理机制。咨询正文 1 年保留是默认产品策略，正式交付前仍应在客户协议和隐私政策中明确，并允许按客户合规要求调整。
